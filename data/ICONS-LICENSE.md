# Infografika ikonlari — litsenziya

`lib/generation/infographic/icons.ts` dagi SVG `path` lar **Tabler Icons**
to'plamidan olingan (`@tabler/icons`, 3.46.0, `icons/outline/`), MIT
litsenziyasi ostida. Atributsiya SHART EMAS, lekin nusxa shu yerda
saqlanadi: paket dev bog'liqlik sifatida olib tashlansa ham chizmalarning
kelib chiqishi ko'rinib tursin.

- Manba: <https://github.com/tabler/tabler-icons>
- Sayt: <https://tabler.io/icons>
- Litsenziya matni: <https://github.com/tabler/tabler-icons/blob/main/LICENSE>
- Qayta yaratish: `npm run gen:icons` (`scripts/gen-icons.mts`)

Ishlatilgan ikonlar ro'yxati `lib/generation/infographic/types.ts` dagi
`ICONS` (41 nom). `sigma` nomi Tabler da `sum` deb ataladi — moslik
jadvali generatorning `ALIASES` bo'limida.
